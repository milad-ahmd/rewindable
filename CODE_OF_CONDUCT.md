# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep discussions about the work rather than the person. Harassment and personal attacks are not tolerated.

To report a problem, contact the maintainer privately through GitHub ([@milad-ahmd](https://github.com/milad-ahmd)). Reports are handled confidentially.
